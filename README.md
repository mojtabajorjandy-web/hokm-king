# 🃏 حکم-کینگ

بازی سنتی ایرانی حکم — آنلاین، رایگان، با بازیکنان واقعی و ربات هوشمند

## ✨ امکانات

- 🎮 بازی آنلاین ۴ نفره با بازیکنان واقعی
- 🤖 جایگزینی هوش مصنوعی هنگام خروج بازیکن از بازی
- ⏱️ ۳ دقیقه محدودیت برای بازیکنی که وسط بازی خارج می‌شود
- 💬 چت زنده بین بازیکنان
- 🎫 دعوت دوستان با کد اتاق برای بازی ۴ نفره
- 🎡 گردونه شانس روزانه رایگان
- 💎 خرید اشتراک برای خود و هدیه دادن به دوستان
- 🏆 لیگ حرفه‌ای
- ⚙️ صفحه تنظیمات (نام، صدا، سرعت بازی ربات، رنگ میز)
- 🟡 میز طلایی، برگ‌های قشنگ و درشت
- 👑 علامت تاج کنار حاکم
